# X投稿くん - 投稿文生成ワークフロー

## 概要

note記事のURLを受け取り、ナレッジに基づいてX投稿文を生成し、
Klavis MCP経由でGoogleスプレッドシートに自動書き込みするスキル。

**スプレッドシート:**
`https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/`
**シート名:** `X投稿`
**Klavis Strata ID:** `YOUR_KLAVIS_STRATA_ID`

---

## ワークフロー全体像

```
[INPUT]
  note記事URL
  投稿数（例: 3本）
  スケジュール（例: 明日 7:00 / 12:00 / 19:00）
  X投稿する / Threads投稿する

      ↓

[STEP 1] 記事取得
  WebFetch で本文・タイトル・キーワードを取得

      ↓

[STEP 2] インサイト分析（00_インサイト分析手法.md）
  - ターゲットの表面的な悩みを特定
  - 本音・潜在的欲求を掘り下げる
  - インサイト指定型ターゲットコールを3案作成

      ↓

[STEP 3] フック選択（02_フック50パターン.md）
  - 各投稿で異なるパターンを選ぶ（連続使用禁止）
  - 4大要素を満たすか確認
    ① ターゲットコール（誰に）
    ② 意外性・逆説（既視感ゼロ）
    ③ 具体的な数字/結果
    ④ 強烈な断定/煽り
  - 140字以内に収める

      ↓

[STEP 4] 投稿文生成（以下ナレッジを必ず全適用）
  短文（通常X投稿）: 03の構造 + 08の法則
  長文（3000字投稿）: 03_長文構造.md の14ブロック構造

      ↓

[STEP 5] AI臭除去チェック（04_AI臭除去.md）
  20項目チェックリストを通過させる
  18項目以上 → 合格

      ↓

[STEP 6] スプレッドシートへ書き込み（Klavis MCP）
  各投稿を行ごとに書き込む
```

---

## STEP 4 詳細 - 投稿文生成ルール

### 必須適用ナレッジ（全投稿共通）

| ファイル | 適用タイミング | 必須チェック項目 |
|---------|--------------|----------------|
| `01_文体DNA.md` | 全文生成時 | 語尾パターン・改行リズム・口語表現 |
| `04_AI臭除去.md` | 生成後 | NGワード回避・文体の揺らぎ |
| `06_既視感ゼロ戦略.md` | 表現選択時 | 前回と同じ切り口を使っていないか |
| `07_繰り返し回避ルール.md` | 全体確認時 | 同じ表現・数字・構造の繰り返しなし |
| `08_100点ポストの絶対法則.md` | 最終確認 | 8法則すべてチェック |

### 文体DNA（デジイナ社長のX投稿スタイル）

```
語尾パターン:
  体言止め: 40%
  「〜から」断定: 30%
  「〜してる」口語: 30%
  ※ 「〜です」「〜ます」は使わない

口語表現（適度に: 3000字で3〜5箇所）:
  「w」「www」← 煽り・皮肉で
  「めちゃ」← 強調で
  「正直」← 本音告白で

改行リズム:
  短文（10〜20字）→ 長文（50〜80字）→ 短文（10〜20字）
  このパターンを3〜4回繰り返す

強調:
  「」かぎかっこ ← セリフ・引用・皮肉
  ※〜※ ← 重要な補足・CTA
  !!! は禁止

論理展開:
  否定（失敗パターン指摘）
  → 肯定（正解提示）
  → 理由・具体例
  → 不安払拭
  → CTA

絶対禁止:
  「お前」呼び、「現実はこう」「答えはシンプル」「結論から言うと」
  「いかがでしたか」「〜が重要です」の多用
  「FOMO」等の英語専門用語そのまま使用
```

### 短文投稿の構造（通常ツイート）

```
[フック]（140字以内）
  ↓ 空行
[本論]（200〜400字）
  ナレッジの対比パターン or フローチャート or 箇条書き
  ↓ 空行
[記事URL]
  ↓ 空行
[ハッシュタグ]（2〜3個）
```

**フックパターン使い分け（記事ごとに変える）:**
- 1本目: A-0 インサイト指定型（最強）
- 2本目: B-1-EX 対比パターン型
- 3本目: C系 具体的数字型 or D系 強烈断定型

## STEP 6 詳細 - スプレッドシート書き込み

### Klavis MCPの呼び出し方

**エンドポイント:**
```
POST https://strata.klavis.ai/mcp/?strata_id=YOUR_KLAVIS_STRATA_ID
Headers:
  Content-Type: application/json; charset=utf-8
  Accept: application/json, text/event-stream
```

**セル書き込みリクエスト（Python で JSON を組み立てる）:**
```python
body = json.dumps({
    "spreadsheet_id": "YOUR_SPREADSHEET_ID",
    "column": "A",      # 列（A〜M）
    "row": 7,           # 行番号（7行目〜）
    "value": "書き込む値",
    "sheet_name": "X投稿"
})
req = json.dumps({
    "jsonrpc": "2.0",
    "id": "A7",
    "method": "tools/call",
    "params": {
        "name": "execute_action",
        "arguments": {
            "server_name": "google sheets",
            "category_name": "GOOGLE_SHEETS_CELL",
            "action_name": "google_sheets_write_to_cell",
            "body_schema": body
        }
    }
})
```

### スプレッドシート列マッピング

| 列 | 内容 | 例 |
|----|------|-----|
| A | 投稿日 | `2026/3/25` |
| B | 時 | `7` |
| C | 分 | `0` |
| D | 投稿内容（本文） | ツイート全文 |
| E | X投稿する | `TRUE` |
| F | Threads投稿する | `TRUE` |
| G〜J | 画像URL（任意） | |
| K | 投稿済み（自動） | GASが更新 |
| L | X投稿URL（自動） | GASが更新 |
| M | Threads投稿URL（自動） | GASが更新 |

### 書き込み開始行の確認

書き込み前に必ず空行を確認する：
```
スプレッドシートのデータ確認 → 最後のデータ行 + 1 から書き込む
（既投稿済みの行を上書きしない）
```

## 投稿生成チェックリスト

### フック確認
```
□ ターゲットコールが明確（インサイト指定型推奨）
□ 既視感ゼロの切り口
□ 140字以内
□ 前回と異なるフックパターン
```

### 本文確認
```
□ 文字だけのブロックが3連続していない（箇条書き/対比を挟む）
□ 具体的な数字・事例が入っている
□ 失敗談または自分の体験が入っている
□ 「」でセリフ・心情描写が入っている
□ 短文→長文→短文のリズム
```

### AI臭除去確認
```
□ 「〜が重要です」は1回以内
□ 「いかがでしたか」使っていない
□ AI臭い繋ぎ言葉なし（「現実はこう」「答えはシンプル」等）
□ 「お前」呼びなし
□ 感情の揺らぎがある（断定→共感→本音 など）
□ 完璧すぎない（適度な口語・冗長さ）
```

### スプレッドシート確認
```
□ 既存データを上書きしていない（7行目〜の空行から書き込む）
□ 投稿日・時・分が正しい
□ E列（X投稿する）= TRUE
□ F列（Threads投稿する）= TRUE（デフォルト）
□ K列（投稿済み）= FALSE（GASが自動更新）
```

---

## 運用ルール

1. **記事1本 → 2〜5投稿**が基本（角度を変えて）
2. **同じ日に詰めすぎない** → 朝7:00 / 昼12:00 / 夜19:00〜21:00
3. **フックパターンは毎回変える**（同じパターン連続禁止）
4. **ナレッジ未参照での投稿文生成は禁止**
5. **書き込み前に必ず最終行番号を確認する**
